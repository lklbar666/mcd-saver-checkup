# 三个可以直接复制的问法

## 1. 体检常点的一单

```
帮我体检一下：我平时点巨无霸 + 中薯条 + 中可乐
```

期望输出：四种买法对比 + 最优方案 + 省多少 + 凑单是否划算。

## 2. 只问「要不要凑」

```
我想吃麦乐鸡 10 块（23 元），现在有满 60 减 12，值得凑吗？
```

期望输出：差多少、最少加购什么、加购金额与优惠金额的大小关系、净赚还是净亏。

## 3. 复盘历史订单

```
看看我最近 10 单，有没有买贵
```

期望输出：多少单本可更便宜、共多花多少、主要亏在哪个动作（未用券 / 套餐选错 / 凑单过度）。
